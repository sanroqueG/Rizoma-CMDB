# Logos

- `rizoma-logotipo.svg` — Logótipo horizontal (símbolo + "rizoma" em Inter Bold, em contornos) para fundos claros. Nome em #1f2937 (`text`); placa em #0f6b73 (`primary`).
- `rizoma-logotipo-negativo.svg` — O mesmo, com o nome em branco, para fundos escuros (barra lateral, capas).
- `rizoma-simbolo.svg` — Símbolo isolado: ícone da aplicação, favicon, avatar em redes sociais. Placa #0f6b73, traço branco.
- `rizoma-simbolo-mono.svg` — Só o traço do rizoma, numa tinta (#1f2937), para gravação e documentos a uma cor.

Área de proteção: metade da altura do símbolo. Mínimos: símbolo 16px, logótipo 96px de largura.
