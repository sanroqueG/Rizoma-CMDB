# Acordo de Tratamento de Dados (art. 28.º RGPD)

> RASCUNHO PARA REVISÃO JURÍDICA · Versão [AAAA-MM] · Anexo aos Termos de Serviço

Entre o **Cliente** (responsável pelo tratamento) e **[Denominação social]**, NIPC [número] (o "Rizoma",
subcontratante).

## 1. Objeto

O Rizoma trata dados pessoais por conta do Cliente apenas para prestar o serviço descrito nos Termos de Serviço.

| | |
|---|---|
| **Natureza e finalidade** | Alojamento e gestão do inventário de tecnologia dos clientes do Cliente |
| **Categorias de titulares** | Utilizadores do Cliente; colaboradores e contactos dos clientes do Cliente |
| **Categorias de dados** | Identificação e contacto (nome, email, telefone), utilizador de equipamentos, dados técnicos (hostname, IP, número de série), conteúdos livres que o Cliente escreva (notas, tickets) |
| **Dados sensíveis** | Não previstos. O Cliente não deve registar categorias especiais (art. 9.º) |
| **Duração** | Enquanto vigorar a subscrição, mais o prazo de eliminação (cláusula 8) |

## 2. Instruções

O Rizoma trata os dados só segundo instruções documentadas do Cliente, que são estes termos e as configurações que
o Cliente faz no serviço. Se uma instrução lhe parecer violar a lei, avisa o Cliente.

## 3. Confidencialidade

As pessoas autorizadas a tratar os dados estão obrigadas a confidencialidade. O acesso da equipa do Rizoma aos dados
do Cliente limita-se ao necessário para suporte (a pedido do Cliente) ou para resolver incidentes, e fica registado.

## 4. Segurança (art. 32.º)

Medidas técnicas e organizativas, entre outras: isolamento lógico entre organizações, verificado por testes
automáticos; passwords com scrypt; segredos cifrados (AES-256-GCM); HTTPS; 2FA e login único; registo de auditoria;
cópias de segurança verificadas e com retenção limitada; atualizações de segurança regulares; acesso administrativo
restrito.

## 5. Subcontratantes ulteriores

O Cliente autoriza os subcontratantes listados na Política de Privacidade. O Rizoma avisa com [30] dias de
antecedência a entrada de um novo subcontratante; o Cliente pode opor-se com fundamento razoável e, não havendo
acordo, cancelar sem penalização. O Rizoma impõe-lhes obrigações equivalentes às deste acordo.

## 6. Transferências internacionais

Os dados ficam alojados na UE. Qualquer transferência para fora do EEE só ocorre com garantias adequadas
(decisão de adequação ou cláusulas contratuais-tipo).

## 7. Assistência ao Cliente

O Rizoma ajuda o Cliente a responder a pedidos dos titulares (o serviço permite consultar, corrigir, exportar e
apagar dados) e nas avaliações de impacto e consultas prévias, na medida do razoável.

## 8. Fim do contrato

O Cliente pode exportar os dados a qualquer momento. Com o pedido de eliminação ou o fim do contrato, os dados são
apagados no prazo de 30 dias e as cópias de segurança no fim da respetiva retenção ([N] dias), salvo obrigação legal
de conservação.

## 9. Violações de dados

O Rizoma notifica o Cliente sem demora injustificada, e no máximo em [48] horas depois de ter conhecimento, de uma
violação de dados pessoais que afete os dados do Cliente, com a informação disponível sobre a natureza, as
consequências prováveis e as medidas tomadas.

## 10. Auditoria

O Rizoma disponibiliza a informação necessária para demonstrar o cumprimento deste acordo e permite auditorias,
com aviso prévio de [30] dias, a custo do Cliente, no máximo uma vez por ano (salvo após violação de dados).
